Búho

Monitor on-prem de bases de datos: te dice qué está mal y cómo se arregla — no otro stack de métricas.

Ver en GitHub Instalar en 15 min

Pitch (30 s): Redgate/SolarWinds cuestan +$1k/servidor/año; PMM no cubre SQL Server y arrastra Prometheus. Búho es un colector + PostgreSQL + consola, con checks opinados, alertas (Slack/Teams/Discord/…) e informe semanal. On-prem, sin agente en el host del cliente.

Qué incluye

  • PostgreSQL primero; también SQL Server, MariaDB/MySQL y MongoDB
  • Health score + remediación en español/inglés
  • Alertas nativas: pack de sistema + SQL custom + auto-recovery
  • Parque (backups, disco, jobs, HA), seguridad, análisis de series

Lead gen gratis

  • CLI buho-check: mismos checks, sin store — npm run check -- 'postgres://…'
  • Códigos de salida listos para cron/CI (0/1/2/3)

  • ./install.sh --pull desde tag v1.1.1+
