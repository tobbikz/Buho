Búho

On-prem database monitoring that tells you what is wrong and how to fix it — not another metrics stack.

View on GitHub Install

Redgate and SolarWinds list above $1k per server per year. PMM skips SQL Server and brings Prometheus. Búho is one collector, one PostgreSQL store, and one console: checks with remediation, native alerts, and a weekly report. On-prem. No agent on the database host.

What you get

  • PostgreSQL, SQL Server, MariaDB / MySQL, and Oracle
  • Health score plus remediation
  • Native alerts: system pack, custom SQL, and channels
  • Estate (backups, disk, jobs, HA), security, and time-series analysis
